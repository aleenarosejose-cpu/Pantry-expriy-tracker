# Pantry-expriy-tracker

## Introduction
Pantry Expiry Tracker is a simple Java mini project that helps users keep track of food items stored in their pantry and alerts them before the products expire. This helps reduce food waste and improves pantry management.

## Problem Statement
People often forget the expiry dates of products stored in their pantry. Without a tracking system, items may expire before they are used. This project provides a simple solution to track expiry dates and alert users.

## Features
- Add pantry items with expiry dates
- Store items using arrays and objects
- Display stored pantry items
- Alert user when item is near expiry
- Show message if item expires today

## Java Concepts Used
- Classes and Objects
- Arrays
- Strings
- Conditional Statements
- Loops
- Basic GUI using Java Swing

## How the Program Works
1. User enters the pantry item name and expiry date.
2. The item is stored in an array of objects.
3. When the user clicks "Check Expiry", the program compares the expiry date with today's date.
4. The program alerts if an item will expire within 3 days or today.
